# Roadmap

## 0.1.0 development preview

- [x] Tasks-compatible IDs and explicit safe ID command
- [x] Saved-state observation and before/after timeline
- [x] Change/rescheduling counts, editor context action and sidebar
- [x] Synchronized per-writer JSONL journals
- [x] Duplicate IDs, journal corruption and causal-branch safeguards
- [x] Reproducible build, automated tests and settings-preserving deployment tooling
- [ ] Live desktop and Android verification

## Before public beta

- [ ] Scope settings and safe automatic ID assignment for new/existing tasks
- [ ] Test Tasks-dialog, undo, multiple editors, active typing and background save races
- [ ] Full Tasks syntax/filter integration using supported APIs where possible
- [ ] Review/recover incomplete or divergent journal histories without losing raw data
- [ ] Sync ordering, offline edits, recurrence and large-vault performance testing
- [ ] Improve task selection/search, history filtering and export
- [ ] Accessibility and theme/mobile layout checks
- [ ] Release artifacts, BRAT instructions and publication review

## Later

- [ ] Explicit recurrence series association
- [ ] Supported Tasks render/menu hook integration when available
- [ ] Optional common identity integration with Issue Bridge
- [ ] Task stability/age analytics without fabricated creation times
